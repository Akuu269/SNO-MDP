# Retained Mars application data

These HiRISE/MRO elevation crops and provenance were retained when the project moved to the primary GP-Safety-Gym benchmark. They are not an active runtime adapter. The earlier exploratory terrain/plot/download modules and teaching results were retired; their old commands are unsupported.

Source: https://hirise.lpl.arizona.edu/dtm/ESP_076767_1510  
Format/reference: https://www.uahirise.org/dtm/about.php  
Product: `DTEED_076767_1510_076833_1510_A01`.

Each crop retains the source PDS label, downloaded byte span, elevation array, and hashes. `selection_record.json` records the initial-region validity decisions, including the rejected centered crop. These are inspected development samples, not held-out test sites.

A later Mars experiment needs an audited elevation/safety uncertainty model, independent terrain sites, physical units, and a separate protocol. Do not present the retired direct-margin prototype as the paper's Matérn elevation-GP experiment or a physical rover deployment.
